PROCESS CONCEPTS:

1. Process Abstraction:
- Represents an active program executing inside virtual memory.
- Managed by kernel data structures (Process Control Block) storing PID, PPID, and state.

2. Process Creation (fork):
- fork() clones the caller process into a child process.
- The parent process receives the child's PID, and the child receives 0.
- getpid() retrieves current PID; getppid() retrieves parent PID.

3. Program Execution (exec):
- The exec() family replaces the calling process image with a new executable.
- Retains existing PID while resetting program counter and memory mappings.
- Commonly paired with fork() to execute external binaries concurrently.

4. Parent-Child Relationship & Synchronization:
- Parent manages child termination status using the wait() / waitpid() system calls.
- Prevents resource leaks and orphan/zombie process accumulation.

5. Process Tree Hierarchy:
- Maps all running OS tasks hierarchically rooted at init/systemd.
- Inspected using pstree and formatted ps listings.

6. System Call Tracing:
- The strace utility captures boundary transitions between user space and kernel space.
- Tracks execution flow across core system calls (clone, execve, wait4, read, write).
