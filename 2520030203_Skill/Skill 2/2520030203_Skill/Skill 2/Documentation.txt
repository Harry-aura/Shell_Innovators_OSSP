PROGRAM:
src/shell_loop.c

MAKEFILE:
Makefile

CORE SHELL CONCEPTS:

1. Interactive Main Loop:
- Continuously prompts the user and awaits keyboard stream data.
- Sequentially executes prompt -> read -> process -> repeat cycles until termination.

2. Raw Character Capture & Buffer Management:
- Uses POSIX termios configuration to capture unbuffered single keystrokes.
- Appends input characters into fixed-size character arrays dynamically.

3. Backspace & Visual Deletion:
- Detects ASCII 127 and \b control characters.
- Decrements the active buffer index and sends visual erase escape sequences (\b \b).
- Prevents buffer underflow when index is at zero.

4. Multi-Character Command Processing:
- Accumulates strings until \n or \r carriage return is received.
- Trims trailing whitespace and maps valid tokens to internal handlers.

5. Loop Termination:
- Parses 'exit' strings or EOF signals (Ctrl+D) to break the evaluation loop cleanly.
